\chapter{Notation}\label{app:notation}

The symbols of the book, by topic. Where a symbol has two meanings in different parts of the book (for example
$\beta$, the packing ratio of a fuel and the memory bandwidth of a GPU), the context makes clear which is meant; both are
listed. The code names in the last column are those of WRF~4.6.0.

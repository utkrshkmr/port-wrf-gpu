\chapter{Kernel catalogue}\label{app:kernels}

\begin{outline}[(card B-21)]
A table of every GPU kernel of the port: its identifier (for example K-AW), the routine and lines it replaces, its
template (A to G), its work package, and the tests that cover it. The table is generated from
\code{port/agent/kernels.csv} by \code{book/tools/kernels_tex.py}, so that it never disagrees with the plan.
\end{outline}

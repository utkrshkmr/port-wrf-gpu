\chapter{Test catalogue}\label{app:tests}

Every test of the port, from \code{plan.md} section~13 and the gates of section~14. ``Bitwise'' means identical bits
in every compared value: identical bit-hash traces (\cref{ch:repro}), or identical files. All windowed tests start two
runs from the same restart file, so they do not depend on whether a restart continues a run bit for bit, and they run on
the dev case \code{eaton_small} unless marked ``full case''.

## Questions and blockers

- Entry island sits after the horz_order and vert_order assignments and the unported-order and polar fatals. gen_island names line 4439, which is the statement function flux4, not an executable statement. The fatals have to see the orders and run before any data movement.
- Statement functions are module procedures advect_w_gpu_flux3, advect_w_gpu_flux4, advect_w_gpu_flux5, and advect_w_gpu_flux6 (Template B TMPL_NO_STMTFN). Probe F-STMTFN is not in this tree, so that form was used. time_step is an argument of flux3 and flux5.
- Open radiation loops (open_xs, open_xe, open_ys, open_ye, interior and the k=ktf+1 lid) are extra kernels with no K- id. They are outside KERNEL_REFS, and em_fire executes them. Polar, and orders other than h_sca 5 and v_sca 3, call wrf_error_fatal before the island.
- The vertical column uses index k-kts+1 in vflux_col(WRF_KMAX+1). The kts and kte zeros are inside the column.
- K-ADVW-X is one kernel. Each thread computes faces i and i+1 with the source expressions. Face i+1 is written with (i+1) so there is no ii=i+nface. Full stencil, then degrade_xs, then degrade_xe, as separate IFs, same overwrite order as the source.
- The four single-loop open-boundary lid kernels use collapse(1). Without it, kernel_lint glues if(gpu_on) onto vector and reports a false E1.
